# Google-AI-agents-intensive
This repository contains all the hands-on projects, mini–agent builds, I developed during the Google AI Agent Intensive program. Each project focuses on a core skill from the course including agent design patterns, tool use, prompt engineering, retrieval, planning, and building multi-step autonomous workflows.

The goal of this repo is to document my learning journey while showcasing practical, working AI agents built from scratch. Every folder includes clear explanations, code, and outcomes, making this a growing collection of real-world agent implementations inspired by industry best practices.
